# 🏦 Bank Management System

A Python-based Bank Management System built using Object-Oriented Programming, CRUD operations, JSON data storage, and Streamlit.

## 🚀 Features

- Create bank account
- View account details
- Update account details
- Delete account
- Deposit money
- Withdraw money
- Balance management
- PIN authentication
- Automatic account number generation
- JSON-based data persistence
- Streamlit web interface

## 🛠️ Technologies Used

- Python
- Object-Oriented Programming
- Streamlit
- JSON
- Git & GitHub
